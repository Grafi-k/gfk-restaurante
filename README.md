Bienvenido al repositorio oficial de **GFK Restaurante**, una *Landing Page One Page* dinámica y de alta conversión diseñada para la industria gastronómica. 

Este proyecto forma parte de la serie de tutoriales en el canal oficial de **Grafi-k Digital Web** en YouTube, enfocados en el desarrollo web profesional, diseño de experiencias dinámicas e integración con el ecosistema de WordPress.

---

## 🚀 Características Principales

* **Diseño Responsive & Moderno:** Optimizado para la mejor experiencia en dispositivos móviles y de escritorio.
* **Estructura Modular Clean:** Código organizado en HTML5, CSS3 y JS limpio sin dependencias pesadas innecesarias.
* **Preparado para Gutenberg / WordPress:** Diseñado para integrarse como base de bloques/patrones dinámicos con el plugin `gfk-pluginwebia`.
* **Rendimiento de Carga Rápida:** Optimización de assets y carga ligera para altos estándares de Web Vitals.

---

## 🛠️ Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript (ES6+).
* **Entorno de Prueba:** WordPress Local Server (Nginx / Docker / XAMPP).
* **Arquitectura Objetivo:** WordPress Block API & Gutenberg.
